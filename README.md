# AIKN-COURT

A Unity 3D recreation of a colorful urban basketball court with four colored stadium-seat sections, built from a concept render. The scene combines a geometric painted court, concrete end walls, tiered concrete stands with molded plastic seats, and a landscaped hilltop setting lit in warm golden-hour light.

![Main view](Screenshots/main_view.png)

## Overview

The court sits on a raised platform surrounded by trees, shrubs, a fence and lamp posts. Two concrete walls run the full width of each baseline, and four seating sections stand along the sidelines, each with its own color and name.

| Section | Side | Position | Seat color |
|---|---|---|---|
| Imanzi | Left | Far end | Red |
| Jamaica | Left | Near end | Green |
| Imena | Right | Far end | Yellow |
| Intare | Right | Near end | Blue |

Each section has 4 rows of 10 seats (40 seats per section, 160 in total), placed on stepped gray concrete.

## Features

- Standard-proportion court: 15 x 28 m with lane, free-throw circle, center circle and three-point arc
- Painted geometric floor texture with a separate lines layer
- Full-width concrete walls (15 m) behind both hoops
- Four color-coded seating sections generated by a script (`SeatSection.cs`)
- Section names on the concrete front faces
- Terrain, trees, shrubs, fence, lamp posts and scoreboard
- Warm directional sun, HDRI sky and light post-processing

## Tech

- Unity 6 (6000.4.7f1)
- Universal Render Pipeline (URP), Universal 3D template
- ProBuilder, TextMeshPro, Cinemachine
- C#

## How to open

1. Install Unity Hub and Unity 6 (6000.4.7f1).
2. Click **Add project from disk** in Unity Hub and select this folder.
3. Open the scene `Assets/Scenes/Court.unity`.
4. Press Play to view the scene from the main camera.

## Project structure

```
Assets/
  Art/Textures/     TEX_CourtFloor, TEX_CourtLines
  Art/Models/       imported models
  Materials/        MAT_* materials
  Prefabs/          PF_Seat, hoop, lamp post, fence section
  Scenes/           Court.unity
  Scripts/          SeatSection.cs
```

## Key measurements

| Item | Value |
|---|---|
| Court | 15 x 28 m |
| End walls | 15 m wide, 3.4 m high, 2.2 m behind each baseline |
| Section length | about 7.7 m (10 seats at 0.75 m spacing) |
| Gap between sections on one side | about 3.9 m |
| Stand front distance from sideline | about 1.8 m |
| Rim height | 3.05 m |

Distances were measured from the concept render, so they are accurate to roughly 10-15%.

## How the seating works

`SeatSection.cs` builds one section from a seat prefab. Set the seat prefab, concrete material and seat color on the component, then right-click it and choose **Build Section**. Rows, seats per row, spacing and step heights are adjustable in the Inspector.
